# Helping with FlowClone

Bug reports are welcome via GitHub Issues: something that does not work on your Mac, a
dictation that came out wrong, an update that failed.

When opening an issue, please include:

- Your Mac model and macOS version
- The FlowClone version and build (Settings > Updates & diagnostics)
- What you did, what you expected and what happened
- The relevant lines of `~/Library/Logs/FlowClone.log` (Settings > Updates & diagnostics >
  Diagnostics & maintenance > Open log). The log records events and timings, not what you
  said, unless you turned transcript logging on yourself. Read it before posting, and leave
  out real dictations, meeting notes, API keys and anything else private.

Andre directs development with AI assistance and accepts feedback through issues only.
Outside pull requests are turned off because Andre does not review outside code changes.

For a suspected security vulnerability, please use the private reporting instructions in
[SECURITY.md](SECURITY.md).
